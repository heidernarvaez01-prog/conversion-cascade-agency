# Project rules
- Service pages retain the static HTML template and its animation wrappers/selectors; add concise semantic summaries without rewriting pinned sequences, so visual behavior stays stable.
- Service clarity styling lives in `HTML/css/services-clarity.css` and uses the template's active semantic variables, so light and dark themes stay consistent.
- Global credential navigation is installed in the shared `HTML/js/app.js` before animation initialization, so all pages retain the same downloadable PDF access without editing generated blog pages.
- APaCHe 360 may appear in the service directory and contextual links but stays outside the main service submenu, preserving the brand's navigation constraint.
